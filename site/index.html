PRIVATE BY CRYPTOGRAPHY

No key. No readable message. No magic claims.

Checkpoints and message payloads use authenticated AES-256-GCM; canonical JSON receipts commit to terms digests and optional Ed25519 signatures; HPKE wraps consent-gated artifact keys; additive Paillier aggregation proves exact collective totals (SealedProofBundle) without exposing individual inputs to the evaluator.

Established primitives, bounded claims. AES is a NIST-standardized encryption algorithm. Unlike public-ledger transactions, Nexum encrypts agreement checkpoints and message contents locally before any handoff.

Clear limits: Nexum v2.2.0 is experimental open-source software, not production custody or a deployed consensus network. Your runtime holds and protects keys; the running host can inspect memory and keys, and intended recipients can retain or forward what they decrypt. Additive Paillier aggregation is not general FHE, and the cryptography has not yet undergone an independent security audit.
